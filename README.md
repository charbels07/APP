# CAA — Augmentative & Alternative Communication app (first draft)

Tablet-first AAC app for French, English and Lebanese Arabic, built from the
*Cahier des charges CAA*. This is **draft 0.1**: the mechanics are real, the
vocabulary and boards are **placeholders** that the speech-language therapist
must replace and validate.

**Live demo (browser):** https://claude.ai/artifact/6KiN8TkiZfScTfEq8HAqzS
(private until shared from the page's *Share* menu). Caregiver code: `1234`.

## Stack

- **Expo SDK 58 / React Native 0.88 / TypeScript.** One codebase for iPad,
  Android tablets and the web demo. iOS builds run in the cloud with EAS
  (`npx eas-cli build -p ios`), so no Mac is required to build.
- No backend yet: everything is stored on the device (offline-first, spec §32).
  Profiles are versioned (`src/lib/storage.ts`) so cloud sync can be added later.
- Pictograms: ARASAAC. The starter vocabulary's pictograms are in `assets/arasaac/`; an offline
  library of ~9,000 more (one per French keyword, 160 px WebP, base64 packs) is in `assets/picto/`,
  built by `npm run build:picto` (needs ImageMagick).
- Speech recognition: `expo-speech-recognition` (native module: needs a development build or an
  EAS build, not Expo Go).

## Run it

```bash
npm install
npm run web          # browser
npm start            # Expo dev server (Expo Go / dev build on a device)
npm test             # unit tests (grammar, search, data integrity)
npm run typecheck
```

`EXPO_OFFLINE=1` in front of `expo` commands avoids network lookups in
restricted environments.

## Where things are

| Path | What |
| --- | --- |
| `src/data/concepts.ts` | Every word as a language-independent concept (FR / EN / AR + feminine forms + search tags). **Placeholder content.** |
| `src/data/defaults.ts` | Core board layout (7×12, progressive-reveal levels), folders, TLAs, schedules, default settings. **Placeholder content.** |
| `src/data/arasaacMap.ts` | Generated by `npm run fetch:arasaac` (pins in `scripts/arasaac-pins.json`). |
| `src/data/tlaSeeds.ts` | Starter word lists for common TLA topics (zoo, birthday, dentist…). **Placeholder content.** |
| `src/lib/pictoSearch.ts`, `pictoLibrary.ts` | Offline pictogram search and topic suggestions. |
| `src/lib/parseSentence.ts` | Dictated sentence → board words (for animated modelling). |
| `src/lib/boardOps.ts` | Move / swap cards, spread a card over empty slots. |
| `src/lib/grammar.ts` | Sentence strip grammar: FR/EN conjugation, elision, negation, code-switching segments. |
| `src/lib/search.ts` | Multilingual, typo-tolerant search + "show me where" locations. |
| `src/lib/speech.ts` | On-device TTS + playback of recorded words. |
| `src/lib/printHtml.ts` | Print / PDF layouts (A4/A3, B&W, cut cards). |
| `src/state/AppState.tsx` | App state: strip, navigation, highlight guidance, timer, caregiver mode. |
| `src/ui/` | Screens, universal bar, grid, panels. |

## Spec coverage (draft 0.1)

Done: core board with stable positions and progressive reveal · Fitzgerald
colour code · folders · sentence strip (speak all / per word, delete, clear with
undo) · FR/EN grammar · instant language switch FR ↔ EN ↔ Lebanese Arabic with
the same motor plan · code-switching inside one sentence · universal bar (CAA,
TLA, Schedule, Timer, Help + search, keyboard, language, caregiver lock) ·
search with typo tolerance, synonyms and "show me where" · keyboard · 4 TLAs ·
2 schedules (now / next / done, linked TLA and timer) · First–Then · timer
(circle / bar / digits, keeps running, sound + haptics) · 3-level Help button ·
protected caregiver mode (PIN) · word editor (labels ×3, photo from camera or
library, ARASAAC search, emoji, display mode, colour, reveal level, voice
recording per language) · custom words · new TLAs and schedules · settings ·
print / PDF · profile export · no sentence history (privacy by default).

Draft 0.2 adds: the spoken word follows the grammar ("je" + "vouloir" says "veux") · Pause button
next to Help, both larger · offline pictogram library with automatic picture for new words · TLA
creation from a topic with suggested words (editable before and after) · per-card size, spread
over empty neighbours, colour strength · moving words in caregiver mode · voice dictation and
recorded demonstrations replayed with an animated hand (*Modèle*).

Not yet (later phases of the spec): accounts, multi-device sync, roles and
companion app, AI generation from free text or photos, switch scanning / eye gaze,
Arabic morphology, other dialects, opt-in usage statistics, version history.

## Before the App Store

- **ARASAAC licence**: pictograms are CC BY-NC-SA (non-commercial). A commercial
  licence from the Government of Aragón is required before selling. The symbol
  layer is abstracted (`SymbolRef`), so another set can be swapped in if needed.
- **Arabic voice**: devices only offer a Standard Arabic voice; Lebanese words
  should get recorded audio (word editor → *Voix enregistrée*).
- Regulatory review (EU MDR), privacy policy, Apple developer account.
