# CAA — Augmentative & Alternative Communication app (first draft)

Tablet-first AAC app for French, English and Lebanese Arabic, built from the
*Cahier des charges CAA*. This is **draft 0.1**: the mechanics are real, the
vocabulary and boards are **placeholders** that the speech-language therapist
must replace and validate.

**Live demo (browser):** https://claude.ai/artifact/6KiN8TkiZfScTfEq8HAqzS
(private until shared from the page's *Share* menu). Caregiver code: `1234`.

## Stack

- **Expo SDK 58 / React Native 0.88 / TypeScript.** One codebase for iPad,
  Android tablets and the web demo. iOS builds run in the cloud with EAS
  (`npx eas-cli build -p ios`), so no Mac is required to build.
- No backend yet: everything is stored on the device (offline-first, spec §32).
  Profiles are versioned (`src/lib/storage.ts`) so cloud sync can be added later.
- Pictograms: ten open libraries that are free for commercial use (Mulberry, OpenMoji, Fluent Emoji,
  Noto Emoji, Twemoji, Health Icons, Material Symbols, Phosphor, Lucide, Tabler: about 24,400
  pictograms, no ARASAAC). Licence check: `docs/PICTOGRAM-LICENSES.md`; libraries and versions:
  `pictograms/libraries.json`; full database (one line per pictogram): `pictograms/database/`.
  The built-in words' pictures are in `assets/symbols/`, the whole library (160 px WebP, base64
  packs, FR/EN/AR search index) in `assets/picto/`. Rebuild: `npm run fetch:picto` (downloads the
  originals next to the project), `npm run build:picto`, `npm run build:symbols`.
- Speech recognition: `expo-speech-recognition` (native module: needs a development build or an
  EAS build, not Expo Go).

## Run it

```bash
npm install
npm run web          # browser
npm start            # Expo dev server (Expo Go / dev build on a device)
npm test             # unit tests (grammar, search, data integrity)
npm run typecheck
```

`EXPO_OFFLINE=1` in front of `expo` commands avoids network lookups in
restricted environments.

## Where things are

| Path | What |
| --- | --- |
| `src/data/concepts.ts` | Every word as a language-independent concept (FR / EN / AR + feminine forms + search tags). **Placeholder content.** |
| `src/data/defaults.ts` | Core board layout (7×12, progressive-reveal levels), folders, TLAs, schedules, default settings. **Placeholder content.** |
| `src/data/symbolMap.ts` | Picture of each built-in word, generated by `npm run build:symbols` (choices by hand in `pictograms/default-overrides.json`). |

| `src/data/situations.ts` | Situation library for new TLAs (~45 situations: words + ordered steps, e.g. « préparer un gâteau »). `mot#library/file` pins the pictogram for homonyms. **Placeholder content.** |
| `src/lib/tlaPlanner.ts`, `aiPlanner(.web).ts` | TLA proposal: situation library → AI proposal → pictogram topics. |
| `src/lib/pictoSearch.ts`, `pictoLibrary.ts` | Offline pictogram search and topic suggestions. |
| `src/lib/appLinks.ts` | App pictograms (YouTube, WhatsApp, Spotify, Anghami…): links, trigger words, "which app does this sentence ask for". |
| `src/lib/webPictures.ts`, `clipboardImage(.web).ts` | Pictures from the internet: Global Symbols pictogram sets and Openverse photos/drawings (with licence), paste an image, image link. |
| `src/ui/DrawPad.tsx`, `VoiceButton.tsx`, `wiggle.ts` | Finger drawing pad (search by drawing), microphone button (dictation, search by voice), pictogram wiggle animation. |
| `src/data/guide.ts`, `src/ui/panels/GuidePanel.tsx` | In-app guide content (FR/EN, quotes the real button names — a test checks them) and its panel / welcome card. |
| `src/lib/parseSentence.ts` | Dictated sentence → board words (for animated modelling). |
| `src/lib/boardOps.ts` | Move / swap cards, spread a card over empty slots. |
| `src/lib/grammar.ts` | Sentence strip grammar: FR/EN conjugation, elision, negation, code-switching segments. |
| `src/lib/search.ts` | Multilingual, typo-tolerant search + "show me where" locations. |
| `src/lib/speech.ts` | On-device TTS + playback of recorded words. |
| `src/lib/printHtml.ts` | Print / PDF layouts (A4/A3, B&W, cut cards). |
| `src/state/AppState.tsx` | App state: strip, navigation, highlight guidance, timer, caregiver mode. |
| `src/ui/` | Screens, universal bar, grid, panels. |

## Spec coverage (draft 0.1)

Done: core board with stable positions and progressive reveal · Fitzgerald
colour code · folders · sentence strip (speak all / per word, delete, clear with
undo) · FR/EN grammar · instant language switch FR ↔ EN ↔ Lebanese Arabic with
the same motor plan · code-switching inside one sentence · universal bar (CAA,
TLA, Schedule, Timer, Help + search, keyboard, language, caregiver lock) ·
search with typo tolerance, synonyms and "show me where" · keyboard · 4 TLAs ·
2 schedules (now / next / done, linked TLA and timer) · First–Then · timer
(circle / bar / digits, keeps running, sound + haptics) · 3-level Help button ·
protected caregiver mode (PIN) · word editor (labels ×3, photo from camera or
library, pictogram search, emoji, display mode, colour, reveal level, voice
recording per language) · custom words · new TLAs and schedules · settings ·
print / PDF · profile export · no sentence history (privacy by default).

Draft 0.2 adds: the spoken word follows the grammar ("je" + "vouloir" says "veux") · larger Help
button (the "I need a break" message lives inside Help) · offline pictogram library with automatic picture for new words · TLA
creation from a topic with suggested words (editable before and after) · per-card size, spread
over empty neighbours, colour strength · moving words in caregiver mode · voice dictation and
recorded demonstrations replayed with an animated hand (*Modèle*).

Draft 0.3 adds: smarter TLA creation — a situation library recognises what the family types
(« préparer un gâteau » → flour, eggs, sugar, whisk, mould, oven… and the steps in order, not
the birthday party), an AI proposal for unknown topics (with Lebanese labels; only in the web
demo for now, the iPad app will need a small server), and the steps can become a schedule
linked to the TLA with timers (oven: 30 min) · pictograms chosen by meaning, not just by
keyword (« moule » is the cake tin, not the mussel; « où » is not « ou ») · during modelling,
folders are pressed exactly like words (aim, press, name spoken, then the folder opens).

Draft 0.4 adds: search by voice (« Dire le mot ») and by drawing (the drawing is recognised by
AI — web demo only for now, like TLA proposals) · pictures from the internet for any word (free
pictogram sets whose licence was verified — Mulberry and OpenMoji —, CC photos and drawings for commercial use, paste an
image copied anywhere, or an image link; the author and licence are kept) · setting to make
pictograms wiggle when touched and while they are said (word by word when the sentence is read)
· app pictograms in a new « applis » folder (YouTube, WhatsApp, Spotify, Anghami) that open the
app after a 3-second countdown; a spoken sentence that mentions an app opens it (« je veux
écouter de la musique » → Spotify, trigger words editable); WhatsApp starts without a link and
tells the parents how to add it. Older saved profiles get the folder in its empty slot.

Draft 0.5 adds: an in-app guide from A to Z (bar → *Guide*, and Settings), in two tracks —
first steps for families and new users, and caregivers & professionals — with a “Try it” button
per chapter that opens the place it describes; a welcome card offers it once on first launch.

Draft 0.6 adds: the navigation language (menus, buttons, messages, guide) is chosen separately
from the words' language, both from the bar's *Language* button: French, English or Arabic
navigation × French, English or Lebanese Arabic words. Arabic navigation (simple Modern Standard
Arabic, to be reviewed) mirrors the menus right to left; boards are never mirrored (motor plan).

Draft 0.7 adds: voice type (device / female / male) and voice age (adult / child) in Settings →
Voice. The matching device voice is picked per language by name (`src/lib/voices.ts`); a child
voice is the chosen voice with a higher pitch (tablets have no real child voices); when a language
has no voice of that kind, the default voice is pitched towards it and Settings says so.

Draft 0.8 adds: a minimum delay between two presses on the same pictogram (Settings →
Communication, 2 s by default, off / 1 / 2 / 3 / 5 s): repeated taps no longer fill the sentence
with "pas pas pas"; other pictograms stay usable at once, replays and dictation are not limited.

Not yet (later phases of the spec): accounts, multi-device sync, roles and
companion app, AI generation from photos, on-device/server AI for TLAs on iPad, switch scanning / eye gaze,
Arabic morphology, other dialects, opt-in usage statistics, version history.

## Before the App Store

- **Pictogram licences**: ARASAAC (CC BY-NC-SA, non-commercial) is no longer used. The libraries
  in the app allow commercial use; their obligations (credits page, share-alike for modified
  drawings, never selling the pictograms themselves) and the points to show a lawyer are in
  `docs/PICTOGRAM-LICENSES.md`.
- **Arabic voice**: devices only offer a Standard Arabic voice; Lebanese words
  should get recorded audio (word editor → *Voix enregistrée*).
- Regulatory review (EU MDR), privacy policy, Apple developer account.
